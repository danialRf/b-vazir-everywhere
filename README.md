# B Vazir Everywhere (Firefox)

یک افزونهٔ سبک برای Firefox که فونت متن تمام سایت‌ها را، از نخستین لحظهٔ بارگذاری تا محتوای اضافه‌شده بعدی، به **B Vazir** تغییر می‌دهد. این افزونه هیچ داده‌ای جمع‌آوری یا ارسال نمی‌کند.

## پیش‌نیاز

اگر فونت **B Vazir** یا **Vazir** روی سیستم نصب باشد، افزونه همان را استفاده می‌کند. در غیر این صورت، Vazir همراه افزونه به‌کار می‌رود؛ پس هیچ نصب جداگانه‌ای لازم نیست.

## نصب برای استفادهٔ شخصی

1. فایل‌های این پوشه را به یک ZIP تبدیل کنید؛ خود پوشهٔ پروژه داخل ZIP نباشد و `manifest.json` باید در ریشهٔ ZIP باشد.
2. در Firefox به `about:debugging#/runtime/this-firefox` بروید.
3. **Load Temporary Add-on…** را بزنید و فایل `manifest.json` را انتخاب کنید (نیازی به ZIP نیست).

این روش تا زمان بستن کامل Firefox فعال است. برای نصب دائمی، افزونه باید در [Firefox Add-ons](https://addons.mozilla.org/developers/) امضا و منتشر شود؛ پس از آپلود ZIP، Firefox نسخهٔ امضاشدهٔ XPI را می‌سازد که می‌توانید نصبش کنید.

## محدودیت‌های فنی

تغییر فونت در صفحات داخلی Firefox (`about:`)، تب‌های خصوصی مگر با فعال‌سازی دستی افزونه برای Private Windows، و shadow DOMهای بسته ممکن نیست. محتوای معمولی و محتوای افزوده‌شدهٔ بعدی بدون نیاز به کلیک یا تنظیم اضافی پوشش داده می‌شود.
