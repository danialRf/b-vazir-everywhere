# B Vazir Everywhere (Firefox)

افزونه‌ای سبک برای تغییر امن فونت متن سایت‌ها به **B Vazir/Vazir**. پنل افزونه امکان روشن و خاموش‌کردن کلی یا غیرفعال‌کردن برای هر سایت را می‌دهد.

نسخهٔ 2.0 با یک قانون CSS سبک، متن موجود و محتوای جدید صفحه را به فونت وزیر همراه افزونه تغییر می‌دهد. برای DOM معمولی هیچ اسکن دائمی انجام نمی‌شود؛ یک observer سبک فقط ساخته‌شدن Shadow DOM را تشخیص می‌دهد تا متن داخل componentهای ایزوله، حتی closed rootهای Firefox، نیز پوشش داده شود. فقط خود عنصرهای آیکن‌فونت، SVG و فرمول‌های ریاضی مستثنا می‌شوند؛ containerهای عمومی مانند `aria-hidden` یا فرزندان wrapperهای آیکن دیگر از تغییر فونت حذف نمی‌شوند. پنل افزونه نسخه و وضعیت واقعی اعمال فونت را از همان تب نمایش می‌دهد.

## فونت

نسخهٔ متن‌باز Vazir داخل افزونه قرار دارد و همیشه همان فایل استفاده می‌شود؛ بنابراین نصب جداگانه‌ای لازم نیست و نتیجه روی سیستم‌های مختلف یکسان است.

## نصب موقت برای آزمایش

1. در Firefox به `about:debugging#/runtime/this-firefox` بروید.
2. روی **Load Temporary Add-on…** بزنید.
3. فایل `manifest.json` را انتخاب کنید.
4. پس از هر تغییر در پروژه، در همین صفحه روی **Reload** بزنید و سایت را رفرش کنید.

نصب موقت با بستن کامل Firefox حذف می‌شود. برای نصب دائمی، بسته باید در [Firefox Add-ons](https://addons.mozilla.org/developers/) امضا شود.

## استفاده

آیکن قرمز افزونه را در نوار ابزار باز کنید:

- کلید **تغییر فونت** افزونه را برای همهٔ سایت‌ها روشن یا خاموش می‌کند.
- کلید **سایت فعلی** فقط دامنه‌ای را که باز است مستثنا یا دوباره فعال می‌کند.

تنظیمات فقط داخل Firefox ذخیره می‌شوند. افزونه هیچ اطلاعاتی جمع‌آوری یا ارسال نمی‌کند.

## محدودیت‌ها

Firefox اجازهٔ تغییر صفحات داخلی `about:`، صفحه‌های محافظت‌شدهٔ Mozilla، PDF viewer و shadow DOMهای بسته را به افزونه‌ها نمی‌دهد.
